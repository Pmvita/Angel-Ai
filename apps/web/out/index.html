Interview & meeting desk

AngelAi

Invisible real-time assistance for high-stakes conversations — listen, see the screen, ask the transcript, and ship notes before the call ends.

Try the web deskDownload desktop

Full Listen / Vision / Ask / Notes needs the local API (`apps/server`) or the desktop app. The web desk falls back to a browser demo when the API is offline.

Listen

Live transcription from your mic so you never lose the thread mid-interview.

Vision

Periodic screen capture with AI summary, key points, and action items.

Ask

Question the live transcript with OpenAI, Anthropic, Google, OpenRouter, or local models.

Notes

Manual and auto notes, translation, and export to Markdown, PDF, TXT, or email.

Kill switch & screen-share caveat

`Cmd/Ctrl+Shift+S` hides the overlay instantly. The window is visible to screen capture — hide it or move it to a non-shared monitor before sharing your screen.
